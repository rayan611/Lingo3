# Lingo3 — Product Charter

Document ID: PRODUCT-LINGO3-001
Version: 1.0.0
Status: approved by product owner; pending merge
Updated: 2026-11-01

## Mission
Help learners acquire, retain, and use vocabulary across multiple languages with efficient, personalized practice.

## Target users
Independent learners studying one or more languages.

## User value
Reduce forgetting and wasted practice with spaced repetition, contextual examples, grammar and pronunciation support.

## Core scope
Personal vocabulary library, FSRS-style reviews, multilingual examples, pronunciation, offline use and sync.

## Product boundaries
Do not claim fluency or guaranteed exam outcomes from vocabulary reviews alone.

## Success metrics (proposed, not yet measured)
Review consistency, retention, sync reliability, active learners.

## Change management
Propose edits in a dedicated branch and pull request. Record motivation, user impact, version bump, and approvals. Approved Git content is authoritative; the management database stores a versioned, SHA-linked synchronized copy. Do not silently alter product scope.
